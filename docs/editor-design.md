# 视差工坊

目标：把现有画廊改成无需编辑源码的图片特效网站，并上传到指定的 GitHub 仓库。

## 使用方式

- 同一页面切换 2D 横向视差与 WebGL 画廊。
- 上传、拖入、替换、前移、后移和删除图片；可添加原版霓虹示例。
- 每张图片选择无效果或七种已有悬停效果，可应用到全部图片。
- 中文滑块实时调整原有着色器参数、滚动速度、图片间距、高度、比例和背景。
- 全屏预览保持原来黑底横向画廊的展示方式。
- 自动保存当前浏览器草稿，JSON 备份内嵌全部图片，可在新浏览器恢复。

## 实现范围

复用 React、Three.js、GSAP 和现有着色器。编辑器、项目数据与画廊渲染分别负责 UI、保存校验和实时效果。参数变化更新 uniforms；只有图片源或渲染模式变化会重新创建渲染器。鼠标、滚轮和键盘监听只作用于画廊，不拦截编辑面板。触摸拖动支持移动端。

IndexedDB 保存图片和参数，不将用户上传的照片发送到服务器，也不包含跨设备云同步。GitHub Pages 托管完整编辑网站；现有 vinext 开发服务继续运行同一编辑器。备份导出负责将示例图片转为嵌入式数据，避免依赖部署路径。

## 验收

检查上传、替换、排序、删除、刷新恢复、七种效果的实际像素差异、2D 滚动、参数更新、全屏预览、移动布局、无效图片与备份拒绝、新浏览器导入、项目子路径静态构建和线上加载。
